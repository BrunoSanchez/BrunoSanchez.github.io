Common Issues & Solutions

Issue 1: Plain HTML, no styles

Symptom: You see plain text without any colors or formatting.

Cause: CSS file not loading (probably due to incorrect path or Jekyll not running).

Solution:

  1. Make sure you're running Jekyll: bundle exec jekyll serve
  2. Access via http://localhost:4000 (NOT file:// URLs)
  3. Check terminal for errors

Issue 2: Images not showing

Symptom: Broken image icons where photos should be.

Cause: Image paths not resolving correctly.

Solution:

  1. Verify imgs/headshotBOS.jpg exists
  2. Check _config.yml has correct baseurl
  3. Clear browser cache (Ctrl+Shift+R or Cmd+Shift+R)

Issue 3: Opening HTML file directly

Symptom: File path in browser shows file:///...

Cause: Opening HTML files directly without a server.

Solution:

  1. Never open HTML files directly in browser
  2. Always use Jekyll server: bundle exec jekyll serve
  3. Access via http://localhost:4000

How to Run Jekyll Properly

# Step 1: Install dependencies (first time only)
bundle install

# Step 2: Serve the site
bundle exec jekyll serve

# Step 3: Open in browser
# Go to: http://localhost:4000

See LOCAL_PREVIEW.md for detailed instructions.
